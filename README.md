# Bike-Sales-Analytics

## Project Overview
This project explores customer demographic and purchasing data to identify the primary factors influencing whether a customer purchases a bike. Built entirely within Google Sheets, this project demonstrates data cleaning, categorical feature engineering, pivot table modeling, and interactive dashboard UI design.

## Project Objectives
- Analyze overall bike purchase distribution across the customer base.
- Examine the correlation between customer income levels and bike purchasing decisions.
- Evaluate purchasing trends across demographic dimensions (Marital Status, Gender, Age, Education, and Occupation).
- Assess the impact of commute distance and homeownership on customer behavior.
- Build a cloud-based, interactive Google Sheets dashboard for stakeholder exploration.

## Tools and Technologies
- Google Sheets (Data Cleaning, Pivot Tables, Pivot Charts, Slicers, Data Validation)

## Dataset
- **Records:** 1,026 customer profiles.
- **Attributes:** ID, Marital Status, Gender, Income, Children, Education, Occupation, Home Owner, Cars, Commute Distance, Region, Age, and Purchased Bike status.

## Key Insights & Business Impact
- **Income & Age Groups:** Middle-aged customers and moderate-to-high income brackets show distinct purchasing clusters.
- **Education & Role Impact:** Customers holding Bachelor's or Graduate degrees, as well as Professional roles, demonstrated higher conversion rates.
- **Marital Status Dynamics:** Single customers showed a higher relative purchase propensity compared to married customers within specific income brackets.
